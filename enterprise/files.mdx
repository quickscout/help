Open a project, then **Files** in the rail. Choose **Documents** or **Storage** at the top.

## Documents: read and discuss

Upload a PDF, image or Office document in **Documents**. QuickScout processes it for the project discussion. Wait for processing to finish before asking about its contents.

- Each document shows its processing state. Use **Reprocess** if it failed or needs another pass.
- Use **Download** to save the original and **Delete** to remove it.
- The discussion beside the list asks about the project's processed documents. It uses [credits](/enterprise/credits).

Maps, reports and well information belong here. For LAS files and log scans, use [Uploads](/enterprise/well-logs#upload-logs). For CSV or other data tables, use [Datasets](/enterprise/datasets).

## Storage: organize originals

**Storage** lists everything stored under the project, including files that haven't been processed for discussion.

- Upload files into the current folder.
- **Create folder** adds a folder. Use the folder list and breadcrumbs to move around.
- A file's actions let you download, move or delete it.
- Synced data files are managed through [Datasets → Cloud sync](/enterprise/datasets#keep-data-across-devices).

A file appearing in Storage does not mean it has been processed for discussion. Check **Documents** for that state.
